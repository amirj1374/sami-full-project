# Definition of Done

- implementation and review are complete;
- backend, frontend and API contracts are aligned;
- backend permissions and tenant isolation are verified;
- any migration is new, forward-only and tested on PostgreSQL;
- unit, integration, contract, frontend and workflow tests relevant to scope pass;
- English/Persian behavior and RTL/LTR are synchronized;
- audit, concurrency, idempotency and failure behavior are verified;
- documentation/backlog/ADRs are updated;
- no secrets or unrelated/generated changes are introduced;
- full diff, acceptance criteria and release impact are reviewed;
- final Git status and unavailable checks are reported.
