# Glossary

| Term | Definition | Useful Persian equivalent |
|---|---|---|
| Tenant | Top-level data-isolation/customer account boundary | مستأجر / فضای سازمانی |
| Company | Legal or managerial organization within a tenant | شرکت |
| Branch | Organizational subdivision | شعبه |
| Store | Operational selling/service location; business boundary still open | فروشگاه |
| Customer | CRM party receiving products/services | مشتری |
| Supplier | Party supplying purchased goods/services | تأمین‌کننده |
| Purchase | Procurement transaction with items and lifecycle | خرید |
| Receipt | Confirmation of quantities/serials received against a purchase | رسید دریافت |
| IMEI | Mobile-equipment identifier captured during purchasing receipt | شناسه IMEI |
| Permission | Atomic server-enforced capability code | مجوز دسترسی |
| Role | Named collection of permissions | نقش |
| Super admin | Role behavior that bypasses normal permission checks | مدیر ارشد |
| Aggregate | Consistency boundary changed through its owning service | تجمیع دامنه |
| Domain event | Fact published after/around a domain state change | رویداد دامنه |
| Outbox | Durable database record awaiting external/event dispatch | صندوق خروجی |
| Idempotency | Repeating a request does not duplicate its business effect | تکرارپذیری امن |
| Optimistic locking | Version-based concurrent-update detection | قفل خوش‌بینانه |
| Flyway migration | Ordered, immutable schema evolution script | مهاجرت پایگاه‌داده |
| Managed file | File metadata/content governed by the newer files module | فایل مدیریت‌شده |
| Lifecycle | Allowed states and transitions of a business record | چرخهٔ عمر |
