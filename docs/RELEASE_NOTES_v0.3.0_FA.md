# یادداشت انتشار نسخه ۰.۳.۰

این نسخه، فرآیند فروش سامانه SAMI را از ثبت مشتری تا دریافت وجه و ثبت اثر مالی تکمیل می‌کند.

- پیش‌فاکتور و سفارش فروش
- تحویل کالا و به‌روزرسانی موجودی
- صدور فاکتور فروش
- دریافت کامل یا جزئی وجه
- جلوگیری از دریافت بیش از مبلغ قابل دریافت
- جلوگیری از ثبت دوباره دریافت
- ثبت اثر دریافت در خزانه‌داری و حسابداری
- کنترل دسترسی بر اساس سازمان، شرکت و شعبه
- کنترل خطاهای مالی و حفظ سازگاری اطلاعات
- بهبود رابط کاربری و نمایش واکنش‌گرا در Sales
- راهنمای مشتری‌محور فارسی برای بخش فروش
