commands. The missing approved boundary was Sales order line provenance: sales
lines accepted only Product identity and confirmation dropped Variant identity.

contract, so it was not expanded speculatively.

- V72 nullable tenant-safe `sales_order_lines.variant_id` with index.
- Sales order DTO/entity propagation and Product/Variant validation.
- Confirmation passes exact Variant identity to Inventory reservation.
- Frontend Sales order types expose optional `variantId` without inventing UI
  selection behavior.
